# KompaFest Cruise

Marketing site for KompaFest Cruise. Static HTML, served via GitHub Pages at https://kompafestcruise.com.

- `index.html` — home
- `music.html`, `faq.html`, `presale.html`, `sponsor.html`, `ambassador.html` — content pages
- `privacy.html`, `terms.html`, `refund.html` — legal
- `images/` — assets
- `screenshot.py` — local viewport screenshot helper
